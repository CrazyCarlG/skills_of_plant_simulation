## 2. 标准流程

### 第 1 步：启动服务（双击或一行命令）

**方法 A：双击 `start_copilot.bat`**

脚本会：
1. 检查 Python、依赖
2. 后台拉起 `uvicorn copilot_service:app`
3. **轮询** `/health` 等到返回 200（首次 5-15 秒，索引加载）
4. 显示 `/health` 结果

**方法 B：手动命令**

```bash
cd "C:\ProgramFiles\Siemens\TecnomatixPlantSimulation2606\Copilot"
"python-3.14.5-embed\pythonw.exe" -m uvicorn copilot_service:app --host 127.0.0.1 --port 8002
```

> `pythonw.exe` 不弹窗；想看实时日志就把 `pythonw` 换成 `python`。

### 第 2 步：提问

**直接问**：
```bash
cd C:\Users\z004bjuu\Documents\skills_of_plant_simulation\Copilot-using
python ask_copilot.py "How do I create a Buffer in SimTalk?"
```

**中文也行**（CoPilot 内部用英文文档，但能理解中文问题）：
```bash
python ask_copilot.py "如何在 SimTalk 中创建一个 Buffer？"
```

**不带参数**（交互输入）：
```bash
python ask_copilot.py
Question> What is the difference between Buffer and PlaceBuffer?
```

### 第 3 步：停止服务

双击 `stop_copilot.bat`，或：
```bash
curl -X POST http://localhost:8002/shutdown
```

## 3. 输出格式

提问后你会看到：

```
[Q] 你问的问题

←───────── LLM 实时流式输出（边生成边打印）─────────

[citations]                              ← 引用的官方文档
  - 文档标题  https://docs.sw.siemens.com/...
  - YouTube Video on 文档标题  https://youtu.be/...

[metrics] 11.58s  tools=0  tokens_in/out=0/0   ← 耗时 + 工具调用次数
```

`tokens_in/out=0/0` 是因为部分 LLM provider 不在响应里带 token 计数（如某些 OpenAI 兼容接口），属正常。

## 4. 常见场景

### 4.1 写代码遇到问题

```bash
python ask_copilot.py "How do I iterate over all MUs currently in a Buffer in SimTalk?"
```

### 4.2 查类/方法/属性

```bash
python ask_copilot.py "What attributes does the Station object have? List them with brief descriptions."
```

### 4.3 查某个具体函数用法

```bash
python ask_copilot.py "Explain the .move method of Part in SimTalk with examples."
```

### 4.4 学习一个概念

```bash
python ask_copilot.py "What is a WorkerPool and how do I configure shifts?"
```

### 4.5 想看流式效果 vs 直接拿结果

当前脚本**只**走 `/query/stream`（实时显示 token）。如果你只想看最终答案，按 `Ctrl+C` 中断、然后再问时把脚本里 `print(payload, end="", flush=True)` 那行删掉就行。

## 5. 进阶：当作 Python 模块调用

把 `ask()` 当函数用，嵌进自己的脚本：

```python
import sys
sys.path.insert(0, r"C:\Users\z004bjuu\Documents\skills_of_plant_simulation\Copilot-using")
from ask_copilot import ask

# 拿到结构化结果
result = ask("What is a Buffer?")
print("ANSWER:", result["answer"])
print("CITATIONS:", result["citations"])
print("METRICS:", result["metrics"])
```

适合：批量问题、自动化脚本、写进 CI 工具等。

## 6. 故障排查

| 症状 | 原因 | 解决 |
|---|---|---|
| `连不上 CoPilot 服务` | 服务没起 | 跑 `start_copilot.bat` |
| `agent 未就绪` | 没配 LLM 凭据 | 开一次 BrowserView，在 ⚙️ 里选 provider 填 API key |
| 启动卡 30s 不动 | 正在加载 RAG 索引（首次慢） | 等；如果 60s 还不动，看 `Copilot\logs\copilot.log` |
| 中文乱码 / 崩在 `→` | 控制台编码 cp1252 | 已修：脚本会 `sys.stdout.reconfigure(encoding="utf-8")`；或 `set PYTHONIOENCODING=utf-8` 再跑 |
| `mcp_tools: 0` 但问题里出现代码 | 没启 Plant Simulation 进程 | 纯知识问答 OK；如果 agent 想校验代码会失败，启 PS 并加载模型 |
| 双击 bat 一闪而过 | cmd 窗口关闭，看不到错误 | 改成 `cmd /c start_copilot.bat` 从终端跑 |

## 7. 服务端口冲突怎么办

默认 `8002`。被占用就改：

```bash
# 改 bat 里这一行
set "PORT=8123"

# 或临时改环境变量（手动启动时）
set COPILOT_SERVICE_PORT=8123
"python-3.14.5-embed\pythonw.exe" -m uvicorn copilot_service:app --host 127.0.0.1 --port 8123
```

注意：改端口后 `ask_copilot.py` 顶部的 `BASE` 也要同步改。
