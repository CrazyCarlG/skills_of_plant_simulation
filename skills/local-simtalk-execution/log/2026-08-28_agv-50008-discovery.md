## What this run validated / learned
1. simtalk_run 单语句限制:`for i:=1 to ...: print ...; next` 全部错误。`Syntax error near 'print'`。
2. 用 print + readlog 可以枚举节点,但 readlog 在 v15+ 是"延后可见但仍可用"——单次读标记得到了真值,循环跑也没爆炸(只 dump 几十行)
3. `for i in 1..N` 改用循环 shell 多次 send + parse readlog 更稳
4. 命名路径简写很重要:`str_to_obj(".Resources")` 在 simtalk_run context 里解析 OK(已经传到 `reconnected, listening: 50008` 后的新 session)
5. cached `current_*_fresh.json` 数据可信度高,适合预扫
