# 提取代码样例

从 PSFM 模型文件中提取所有可执行的【SimTalk 代码样例】，按以下规则组织：

## 一、代码清单

- 找出所有 Method 对象、以及挂载在对象上的 Control / Observer / Sensor 中的源码。
- 每个代码块按如下格式输出：

```markdown
#### 代码块名称：<Method 名 / 所属对象>（所属Frame：<Frame路径>）
- 触发/调用方式：<被谁调用、何时调用、调用频率>
- 功能说明：<这段代码做什么，2-3 句话>

​```simtalk
<原始源码，原样保留缩进和注释，不要改动>
​```
```

## 二、逐段注释解读

- 对每个代码块中核心的几行，用中文注释解释其作用，尤其是：
  - 访问路径（如 `.MUs.part`、`self.`、`@`、`root.`、`?.` 等）
  - SimTalk 方法调用（如 `move`、`setTypeAndAttr`、`create`、`delete`、`getAttr` 等）
  - 控制流（for/while/if/switch、`waituntil`、`method` 调用）
- 不要只贴代码，必须配解读。

## 三、依赖关系

- 指出每段代码引用的外部对象、变量、表格、方法（即「这段代码能跑起来依赖哪些东西」）。

注意：如果文件中出现的是乱码或二进制片段，请跳过并在清单中注明「该段无法解析」。
