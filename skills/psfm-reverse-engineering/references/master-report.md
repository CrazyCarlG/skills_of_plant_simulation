# 一体化综合产出

对 PSFM 模型文件做一次完整逆向，产出一份结构化的中文文档，标题为「《<模型名称> 模型解析报告》」，包含以下固定章节：

1. 模型概览（定位、目标、一句话描述）
2. 模型结构
   2.1 Frame 层级树
   2.2 对象清单表
   2.3 类结构与继承关系（类继承树 / 实例-类映射 / 继承与引用关系）
   2.4 物料流拓扑图
   2.5 控制与数据流关系
3. 建模思路
   3.1 建模方法与范式
   3.2 控制逻辑梳理
   3.3 关键参数来源
   3.4 建模亮点与局限
4. 代码样例
   4.1 代码块清单（含触发方式 + 功能说明 + 源码）
   4.2 逐段注释解读
   4.3 代码依赖关系
5. 术语表（文中出现的 Plant Simulation 对象/方法英文名 → 中文说明）

约束：

- 对象类型、方法名、属性名必须与 Siemens Plant Simulation 官方帮助文档一致，可参考 `01-plantsimulation-knowledge/01-plant-simulation-help/` 目录。
- 所有结论都要能在 PSFM 文件内容中找到证据；找不到的写「未体现」。
- 输出为 Markdown，代码块用 ````simtalk` 标记。
