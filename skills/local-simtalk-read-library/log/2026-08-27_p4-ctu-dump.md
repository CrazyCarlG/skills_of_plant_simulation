## What this run validated / learned

### Quirk 命中
- **Quirk #6**：`simtalk_run` 的 `data` 字段永远空——print 输出只能走 readlog
- **v15 readlog 截断**：用 BATCH=1 + sleep 1.2 实测 86 个方法全部 dump 完整；
  BATCH=8 估计会丢（这是 v17+ 的标准规避做法）
- **`debug` 关键字**：作为 SimTalk 的内置断点占位，case "Move" / else 分支都用 `debug` 当 TODO

### 新发现的 SimTalk 技巧
- **`executeNewCallChain`**：把方法扔到新 call chain 上异步跑（executor 防重入的核心）
- **`tab_xxx.copyrangeto({0,row}..{*,row}, ...)`**：DataTable 范围复制（任务归档）
- **`tab_xxx.sort(col1, col2, [order1, order2])`**：DataTable 多键排序（默认 up，"down" 反转）
- **`Tab_xxx.setcursor(col, row) + find(value) + cursory`**：DataTable 列内查找
- **`obj._3d.boundingboxmax/min/size/position/dimensions/gap/FloorThickness/GroundClearance`**：
  完整的 3D 几何属性族（MapGenerator 大量使用）
- **`current.~` / `?.` / `?.~`**：跨对象引用语法（生命周期 hook 全靠它）
- **`obj.extendPath("X") /= void`**：检查子对象是否存在（Quirk #9 — Frame.NumChildren 不数实例）

### 用户模型的"教科书"做法（值得抄）
1. **模型打包为类库**：`.P4_CTU` Folder + 模板 Frame + Hardware/Software 分层
2. **BasicObjects 副本**：自包含可移植（继承指向本地副本而非全局类库）
3. **DataTable 即状态机**：所有可变状态都在表里，没有散落 attribute
4. **triggerpoint + _Running + executeNewCallChain**：长跑 worker 防重入
5. **OnCreate/OnMove/OnDelete**：自动注册到控制中枢

### 用户模型的"反模式"（不要照搬）
1. **`messagebox(...)` 在 OnCreate 里** — 卡死 GUI，违反本仓库 v18+ 的 `infoBox(text, false)` 规范
2. **`debug` 关键字当 TODO 占位** — 应该显式 `return false` 或写空 Method
3. **大小写不统一命名**（`m_StockIn` vs `m_init`） — 难 grep
4. **方法名错别字**（`m_get_vihicle_class` 应为 `vehicle`）— rename 时必须查所有引用
5. **死代码**（`m_getDistance` 是空方法、`Tab_ChargingPlace` 多处仅引用不写）
6. **debug 块直接改 MU 颜色**（侵入 3D 状态） — 应该用独立 debug toggle
